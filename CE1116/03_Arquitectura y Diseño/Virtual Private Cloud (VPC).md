## 📚 Idea/Concepto 
Una VPC es un entorno de red virtual aislado dentro de un proveedor de cloud público que permite administrar recursos de manera segura y segmentada. Utiliza tecnologías SDN y planos de control programables para gestionar redes, rutas, firewalls y políticas de tráfico sobre infraestructura compartida.
